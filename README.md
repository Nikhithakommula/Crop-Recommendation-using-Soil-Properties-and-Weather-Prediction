# Crop-Recommendation-using-Soil-Properties-and-Weather-Prediction
Machine learning based crop recommendation system using soil nutrients and weather conditions to suggest the best suitable crop.
## Features
- Crop recommendation based on soil and weather data
- Low data requirement
- Farmer-friendly approach

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest (Best)

## Accuracy
- Random Forest achieved ~95% accuracy

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
